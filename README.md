# highlightauthors

Highlight selected authors in biblatex citations and bibliography entries.

## Usage

```tex
\usepackage[authors={Niemi, Kristian and Malmsten, Bodil},style=bold]{highlightauthors}
```

Options: `authors`, `style` (`bold` or `colorbox`), `color`, and
`highlightincitations`.

## Build and test

```sh
make check
make install
```
